# mografy-film：用 Mografy 做動態圖像

Mografy 的片是一支 TypeScript 場景模組，在 Canvas 上把「時間 t」畫成一格畫面。播放器可以跳到任何一格看，檢查工具會把同一格畫兩次比對，確認沒有藏狀態。它自己附了一份很完整的英文 skill（裝好後在專案的 `.claude/skills/mografy/`），**細節以那份為準**；這份 skill 管的是：什麼時候用它、怎麼裝、方法的重點、和我們其他影片 skill 怎麼分工。

## 什麼時候用它，什麼時候不用

| 要做的 | 用哪個 |
|---|---|
| 從截圖做操作教學，一步一支短片＋一支完整版 | **Mografy**（它最強的一塊，`how-to-film` 流程） |
| 4～12 秒的產品介面小動畫、功能卡、手機畫面 | **Mografy**（十支 `stage-*` 範例片可抄結構） |
| 紙劇場、紙偶風的概念解說、角色小故事 | **Mografy**（`paper-theatre-*` 範例片） |
| 要 Lottie 或 SVGA（給 App、網頁內嵌） | **Mografy**（其他工具都沒有；注意它是逐格圖片封裝，不含向量編輯與聲音） |
| 有旁白、配樂、分鏡的整支解說片 | `sui-motion-graphic-reel`（＋HyperFrames） |
| 同一個畫面換多種畫風 | `style-pack` |
| 用真實網頁擷取做產品宣傳片 | `video-shotcraft` |
| 像素特效 | `pixel-fx` |

## 安裝（第一次要先問 Dex）

在 Dex 的電腦執行第三方程式，第一次一定要先問。2026-11-23 Dex 同意後已裝在 `~/mografy-lab/mografy/`（0.1.2），之後的片直接在那個工作區 `npx mografy init projects/<名稱>`。重裝或裝到別處時：

1. 在要放片的資料夾：`npx mografy@<版本> init`。指定確切版本，不用 `@latest` 浮動。裝在那個資料夾裡、不裝到全域，約 2 MB；Mografy 自己的 skill 會一起裝到 `.claude/` 與 `.agents/`。
2. 它用本機的 Chrome 算圖；FFmpeg 第一次匯出時才下載到專案資料夾，並檢查 SHA-256。
3. `npx mografy dev` 打開本機播放器（localhost）。
4. 更新：在資料夾裡跑 `npx mografy@<新版本>`，先看 GitHub 的 changelog。

資安檢查紀錄（2026-11-23，0.1.2）：skill 只有文件加一支壓縮影片的 Python 腳本（只呼叫 ffmpeg／ffprobe）；npm 套件沒有 install／postinstall 腳本，相依只有 ws、zod、esbuild、protobufjs。CLI 本體沒有逐檔審。

## 做一支新片的流程

1. **讀專案**：`mografy.json`、場景、`style.md`。挑一支最接近的範例片 `npx mografy add <名稱> <資料夾>` 當起點。
2. **Brief**：訊息、對象、長度、比例、畫面上的語言、要不要配樂。寫進 `storyboards/storyboard.md` 開頭。
3. **分鏡**：先寫**一句話的片子點子**：一個貫穿每一鏡、造成每一個變化的視覺東西（例如一條光線依序把每個杯子注滿）。一排各自淡入淡出的卡片不算點子，那就是模板。再把設計系統定成 token 寫進 `style.md`，然後是分鏡表，一鏡一列。只要分鏡就停在這裡。
4. **製作**：一個世界、一台攝影機、一張節拍表（`beats([...])`）。使用者可能想調的部分都宣告成圖層，時間從節拍表來。
5. **配樂**（要才做）。
6. **檢查**：`npx mografy check --motion` 的警告全部處理；`npx mografy review` 產生的每張圖都看，包含每段轉場條。
7. **匯出**：只有被要求時才 `npx mografy export --format mp4|webm|lottie|svga`。

要調長度，從靜止的停留時間拿，不要加快動作。

## 方法重點（我們其他影片也適用）

- **一張節拍表管所有時間。** 每一鏡寫標題、結束時間、定格時間、交棒長度；攝影機關鍵點、圖層出現時間、審片時間全部從這張表算。改一鏡的長度只改表，其他跟著動。
- **一台攝影機貫穿全片。** 卡片、手機、面板在世界裡各自縮放，不另開第二台攝影機；沒有任何一鏡重置回空白正中央。
- **每個剪接點都交棒。** 上一鏡結束在哪條線、哪張卡、哪個點，下一鏡就從它開始；要換場就讓東西長成下一個，不要在同一位置淡出一個、淡入另一個。刻意的換場（硬切、黑場、擦去）只用在故事換段落時。
- **出場和進場重疊 0.2～0.5 秒**，任何一格都不空。
- **一組元素一起淡出**：整張卡片和裡面的列透過同一個圖層變透明，不然重疊的地方會閃。
- **停得夠久**：字幕完整顯示後至少停「0.5 秒＋中文字數 ÷ 4.5」（6 字 ≥ 1.8 秒、12 字 ≥ 3.2 秒）；狀態改變後停 0.6～1.0 秒再做下一個動作；一鏡只做一件事，介面與解說每鏡 2.5～4 秒。（和 `style-pack/references/film.md` 的「動畫結束後再停字數 ÷ 4.5＋1.5 秒」不同，那條比較保守；給初學者看的課程片用那條。）
- **動作要順，不要快**：橫越半個畫面以上至少 0.6 秒，出場至少 0.4 秒；攝影機在動作前最多 0.5 秒先動，點擊與閱讀時不動。
- **設計系統先定**：四種字的角色（小標、大標、項目名、說明）、五種顏色角色（背景、墨色、次要、一個強調色、主體色）、重複的鏡頭用同一個版面、畫面留約 40% 空白、全片一種卡片樣式、logo 只在結尾出現一次。
- **字的大小**（1920×1080）：大標 96～160 px、內文 ≥ 40 px、沒有小於 24 px 的字；直式片字幕放上方三分之一。重畫的介面字放大到原本的 1.3～1.6 倍。

## 繁中注意

- 加 `cjk` 擴充：`npx mografy add cjk <專案>`，附 Noto Sans／Serif CJK TC 子集（OFL）、直排、中文斷行規則（標點不出現在行首）。
- 字定稿後跑它的字型瘦身腳本，只留片中用到的字（約 100～170 KB），每次改字都要重跑。
- 計畫、分鏡表、給工具的提示用英文；畫面上的字用 brief 指定的語言。

## 用在我們的案子

- **練功房、課程的操作教學**：交題、開寶箱、用貓頭鷹問問題這類流程，一步一支 4～8 秒短片，加一支完整版。截圖一律用測試帳號，畫面只放虛構資料，**不出現真實學員的名字、作答或對話**。
- **全齡協會「AI Agent 上工」課**：操作步驟的教學短片（直式加大字幕，給手機看）。
- **散場誌、品牌**：紙劇場風格的概念解說短片。

## 不做的

- 不在 `mografy.json` 寫動畫；不手改 `scenes/timeline.json`（那是使用者在編輯器的改動）。
- 不改專案裡 `examples/` 的範例片；要用就 `npx mografy add` 複製一份再改。
- 不抄別的品牌的文案、標誌、音樂。
- 沒被要求不匯出、不覆蓋 `renders/` 的檔案。
- 操作真的網站或帳號擷取畫面前，要 Dex 給測試帳號並同意；付款、寄信、刪除、邀請人之前一律停下來問。
