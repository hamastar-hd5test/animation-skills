# 場景、時間軸與出片

> 整理自原文的做法，加上 2026-11-23 做 TibaMe 11/24 兩支短片（`~/video-shotcraft-trial/tibame-1124-shorts/`，composition `EtlPipelineStack`、`CareerMapStack`）的實測。那個專案的 `src/stack/`（`core.ts`、`engine.ts`、`StackCanvas.tsx`）是可以直接抄的 Remotion 版起點。錄影模式的網址參數還沒實作過。

## 場景怎麼組

- **地面不是堆疊**：草地色塊、河、路、廣場畫在一張地面畫布上當貼圖。草地用大塊不規則的深淺色塊，不是細碎雜訊。
- **世界比畫面大**：直式片的世界約 400×700（低解析單位），鏡頭才有地方移。
- **擺放**：主角在中央；用固定種子的 Poisson-disc 取樣擺其他物件，避免重疊，路的兩側留空。
- **同一個鏡頭**：所有物件用同一個壓扁值；鏡頭有位置、整數倍縮放、可選的小角度旋轉（旋轉代表所有存起來的靜態物件要重算，預設關）。
- **配色**：暖、柔、略低彩度，色數少。這是「溫馨感」的主要來源。

## 「自己蓋起來」的時間軸

整支片是一條固定時間軸：同一個時間點永遠算出同一格。節奏照這個順序：

| 段落 | 做法 |
|---|---|
| 主角蓋起來 | 素底上只有主角。切片由下往上一片一片掉下來，每片落約 10px、帶小彈跳，每片約 35ms 並互相重疊；底下的影子跟著高度長大 |
| 零件裝上 | 會動的零件用縮放彈一下出現，縮放也要落在整數像素 |
| 安靜的一拍 | 零件開始動，畫面上仍只有主角。這段停頓不能省 |
| 場景往外長 | 一塊不規則的地面從主角腳下像水漬一樣擴張到蓋滿畫面；邊緣掃過哪個物件，它就快速疊起來（每片 8–12ms）並多彈 1px。先後順序＝離中心的距離＋一點固定種子的亂數 |
| 活起來 | 煙、走動的人與動物、沿路走的車、搖晃的作物、流動的水面 |
| 鏡頭漫遊 | 慢慢平移（每秒 6–10 低解析單位），最後回到起點讓影片能循環。鏡頭位置用小數算，貼到畫面時取整 |

直式片上方約 18% 留給平台的字幕區，主角放在垂直方向中間 60%。

## 出片

- **固定步進**：錄影時每格前進固定的 1/60 秒（或 1/30），不看實際時鐘；亂數全部來自同一個有種子的產生器。這樣每次錄都一模一樣，也才驗得了。
- **尺寸**：1080×1920 用 270×480 的低解析畫面 ×4；1080×1350 用 270×338；1920×1080 用 480×270。
- **錄影模式**：網址參數藏掉介面與游標、鎖尺寸、自動播放一次後停在最後一格。
## 接 Remotion（已實測）

- **場景寫成不依賴 Remotion 的純函式**（幀號 → 270×480 的像素），Remotion 元件只負責把結果放大畫出來。好處：在 Node 直接出 PNG 調美術，比 `remotion still` 一張二十多秒快很多；拍號換算另放一份不 import remotion 的檔。
- **畫 canvas**：在 `useLayoutEffect` 裡同步算完再 `putImageData` 就夠，不需要 `delayRender`；同一格渲染兩次位元組相同。放大不要靠 CSS 或 `drawImage`，自己用最近鄰寫進 1080×1920 的 `ImageData`，Node 與瀏覽器結果才一致。
- **效能**：靜態物件連輪廓依（模型、角度、間距）快取、地面惰性快取後，1300 格在並行 2 約 1 分鐘。彎路的最近點計算一定要快取，否則每格慢十倍。
- **推近拉遠**：不要重算切片；場景固定畫 270×480，輸出時裁中間再放大。停留時用整數倍，轉場那幾格允許非整數。
- **直式畫面裝得下多少**：4 倍時一棟建築只有約 200px 寬，偏小；5 倍最多放六棟或三座地標。裝不下就不要硬出全景，改成沿路橫移加微轉。招牌的高度要算進取景，並避開字卡區。
- **對拍**：「蓋起來」要把落成那一格對到拍點，再往回推開始格；落在字卡切點的鏡頭轉場用 easeOut，畫面變化的峰值才會在拍點上。地面擴張掃到物件的時間可以反推：把半徑關鍵格設成各物件到中心的距離。
- **暗場剪影**（還沒被認出來的東西）：同一個模型換一組三階相近的暗色調色盤；輪廓色不能比底色亮，否則變成一圈淡描邊。
- **招牌**：立在自己那棟正上方，有桿子接到屋頂；不要因為碰到字卡就隱藏，用取景避開。
- **讓場景物件飛到 React 圖層的某一點**（例如地標飛進工作表圖的對應格）：需要把螢幕座標反投影回場景（`engine.unproject`），而且要用當格的鏡頭位置算，鏡頭在動時落點才準。
- **同一個動作配兩個音效**（起推的 whoosh＋到位的 tick）：比較響的那個要在拍上；推近用 easeOut 時，到位音放拍上，畫面變化最大的那一刻也剛好在拍上。
- **交付用定格要原尺寸**：專案既有的 `stills.sh` 帶 `--scale=0.5`（調美術用），交付的 1080×1920 定格不能沿用。
- **在直式片裡帶一張橫的原圖**（工作表、截圖）：整張時字一定太小，只當「這是一張圖」的一拍；要讀的內容靠逐格推近，寬的格子要拆兩段推近，每段至少停 2 拍。原圖不要像素化，外框可以用像素風。
- **同一支片出多個片尾版本**（例：活動版／長期追蹤版）：用 composition prop（`ending`）切換，前面完全共用。片尾加了新字時，字型子集裡沒有那些字——另做一個只含新字的小後備字型給新片尾用，不要重裁原子集（會動到既有成片）。
- **比對兩支成片「前面是否相同」**：不能只比解碼後的 MP4，x264 會因後段畫面不同回頭調整前面的編碼；要用 Remotion 對兩版各出幾張定格比雜湊。ffmpeg `framemd5` 要加 `-map 0:v`，否則音訊封包也會算進去。
- **遠景物件（雲）**要用最高的那張字卡檢查會不會被擋，三行字卡會把雲壓成一條白邊，像破圖。
- 字卡、配樂、對拍檢查照 video-shotcraft 既有流程。`learn-promo/` 唯讀，要用就複製。

## 可以拿來做什麼（我們自己的題材）

- 練功房十二站：每站一棟小建築，學習路線就是村裡的路，走過的站亮起來。
- 分享會或課程的開場：主題物件一片一片蓋起來。
- 資料管線：擷取、轉換、載入三棟建築，資料是沿路走的小車。

這些只是方向，做之前照 direction.md 與當次需求決定。
