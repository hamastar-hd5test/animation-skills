# 技法規則與看圖挑錯

## 繪製規則

1. 物件＝一排同尺寸切片，第 0 片是貼地那層，最後一片是頂。每片是該高度的俯視圖。
2. 由下往上畫，後畫的蓋住先畫的。
3. 每片的處理順序：繞切片中心轉 `turn` → 垂直壓扁 `squash` → 往上抬 `round(z × spacing)`。`spacing` 平常是 1。
4. 取樣一律最近鄰。
5. 物件的螢幕位置取整數。
6. 多個物件：整個物件按落地點 y 由小到大畫；y 相同比 x，再比固定的 id，才不會兩個物件互相閃。
7. 鏡頭轉動時：每個物件的位置繞鏡頭中心轉，切片也加上同一個角度；地面貼圖跟著地面畫布一起轉。
8. 會移動的物件面向行進方向：`turn = atan2(vy, vx) − 90°`（再加鏡頭角度），用小幅插值讓轉向不會瞬間跳。

## 明暗

- 每色三階：頂面亮、朝光的側面中、背光的側面暗。
- 光源固定在螢幕左前方，不跟著物件轉。做法是每 45° 預建一組切片（`lightSheets`），依目前角度挑最近的一組（`pickSheet`）。
- 判斷一個體素朝哪一側：往那一側 2 格內是空的（同一層或上一層）就算。上一層也要看，因為上面那片抬 1px 後會露出下面這片「上方是實心」的體素；只看同一層的話，斜屋頂會出現 1px 亮暗橫紋。朝光的斜面（往上 2 層內到頂）與頂面同階，朝光的直牆是中間階，背光是暗階。這條是起手程式與 11/24 短片兩次實測改出來的。

## 看到什麼 → 怎麼改

| 看到 | 原因 | 改法 |
|---|---|---|
| 邊緣糊 | 某個 canvas 開著平滑，或用了 canvas 的旋轉變形 | 每個 context 設 `imageSmoothingEnabled = false`，包含最後放大那步；CSS 加 `image-rendering: pixelated`；旋轉用 `renderStack` 的逐像素反查 |
| 移動或慢轉時閃 | 位置是小數；或沒經過低解析畫面 | 位置取整；先畫進低解析畫面再整數倍放大 |
| 慢轉時抖動仍明顯 | 最近鄰旋轉的先天限制 | 進階：切片先放大 8 倍、旋轉、再取每個 8×8 區塊的中心像素 |
| 身體上有深色雜點線 | 逐片描邊，或輪廓畫進了切片 | 輪廓只在整疊畫完後做一次 |
| 牆面有一圈圈亮點或雜訊 | 斜面邊緣被當成頂面；或切片裡有 1px 細條紋、抖色太密 | 見上方「明暗」；細節至少 2px 寬 |
| 顏色糊成一團 | 用了漸層、柔邊、顏色太多 | 平塗，每物件 4–6 色 |
| 屋頂薄得像紙 | 壓扁低於 0.6 | 用 0.75 |
| 物件前後穿插錯亂 | 逐片排序，或排序點不是落地點 | 整個物件按落地點排 |
| 輪廓是死黑、畫面變髒 | 用了純黑 | 用深暖棕（起手程式是 `#3B2A20`） |
| 斜屋頂有 1px 亮暗橫紋 | 明暗只看同一層的鄰居 | 用起手程式現在的朝向規則（見「明暗」） |
| 鏡頭移動時物件之間互抖 1px | 各自減去小數的鏡頭位置再取整 | 鏡頭位置先取整，再相減 |
| 浮空物件（雲）看不出懸空 | 只有抬高 | 加上下浮動，並和下方建築有連結（影子、往上飄的方塊） |
| 小人在全景認不出來 | 模型太小 | 小人至少約 14 格寬；4–5 倍全景下更小就只是色塊 |
| 物件像浮在空中 | 沒有影子 | 地面之後、物件之前，畫一塊偏右下的扁平影子（地面最深色、約 35% 不透明） |

## 從上游學來的規則（danielwh2/sprite-stacking，2026-11-25）

- 球體會被壓扁與切片間距拉成直立的蛋：垂直半高用 `R_z = R_xy · √(1 − squash²) / spacing`。
- 旗、草、海帶這類固定一端會擺的：每一層水平位移乘上 `(z/(層數−1))²`，底層不動。
- 逐層蓋起來的進場，揭露前緣推到 `層數 + 過渡寬度` 才收，頂層才不會最後一格突然跳。
- 高物件的影子沿太陽方向逐層投影，邊緣用 Bayer 4×4 抖色。
- 細節的密度看「最近的那個鏡頭」決定，不看輸出解析度：50px 的物件放大到 450px 仍然只有 50px 的設計。給 1080p 影片用的主角，可以做到 36–56 層、30–148px，放大 4–6 倍。
- 其餘雕刻相關的規則在 `four-view-carving.md`。

## 效能

- 不會變的物件（房子、樹、圍籬）連輪廓算一次存起來，鏡頭角度沒變就直接貼；只有會動的零件每格重算。
- 會動的物件影格少，也各自存起來。
- 鏡頭外的不畫。
- 不要每格配置新的畫布或陣列（起手示範為了簡短每格重配，正式場景要改成重用）。
- 目標：場景每格約一百多次貼圖，而不是幾千片切片。

## 測試清單（已寫在 stack.test.js）

- 壓扁 1、角度 0：高＝切片高＋（層數−1），寬＝切片寬。
- 壓扁 0.75 比 1 矮；間距 2 比 1 高；轉 90° 寬＝切片高。
- 間距 0、壓扁 1：攤平，只看到最上層。
- 壓扁 1、角度 0：與手動逐片抬 1px 貼上的結果逐像素相同。
- 輪廓像素都貼著剪影、都不在剪影內。
- 落地點 y 大的後畫；同樣輸入算兩次結果相同。
