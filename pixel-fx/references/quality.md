# 看圖挑錯：品質標準與常見問題

整理自 pixelfx 的 `docs/AUTHORING.md` 與它的 skill（MIT，2026-11-22 讀取），用我們的話改寫。原文以 `~/pixelfx/docs/AUTHORING.md` 為準。

## 品質標準（每個特效都要做到）

1. **用線和光，不用大片色塊。** 1 像素的邊、環、軌跡、火花組成形狀，亮度交給光暈層。中心與邊緣白熱，中間帶色，深色只在陰影。
2. **到處都有光。** 低強度的大光暈、核心一個小而熱的光、每個火花與閃點都帶光；打中那一刻有一盞閃一下就熄的光；燒或凍的時候地上有一片暖或冷的光。
3. **煙、霧、灰塵是半透明的。** 上面受光、會膨脹變淡。不要用棋盤格抖色假裝半透明。
4. **真的物理。** 火花跟速度拉長、會掉下來、會彈；碎片翻滾、彈跳、停下、淡出；火往上冒變成煙；落地揚起灰。先快後慢（有阻力）。
5. **分段編排**：蓄力（東西往內聚）→釋放（1～2 格白色閃光格、光、爆開）→擴散→停留（閃點、餘燼）→碎裂或融化→長長的消退。很多小事件，每個大小、速度、時間、壽命都不一樣。
6. **有深度。** 地上的環是扁橢圓，後半圈在角色後面、前半圈在前面；後排的火焰或冰晶比較暗。
7. **節奏：** 出手快、收得慢。大招停留 2～4 秒讓煙散；普通受擊 0.3～0.8 秒但要有餘勢。
8. **原尺寸就看得懂**：一個焦點、形狀裡沒有零碎雜點。
9. **原創**：通用題材可以，不重畫既有遊戲的東西。
10. **乾淨**：不畫出畫布、一次性的結尾是空的、迴圈接得起來、同一個種子每次一樣、每格低於 2 ms。

尺寸基準：內建角色 24×38 像素，細節做到 1 像素。畫布通常寬 96～320 像素；轉場是 320×180。

## 看到什麼問題→怎麼改

| 看到 | 改法 |
|---|---|
| 原尺寸看起來一團糊 | 減色、輪廓清楚、只留一個焦點、形狀放大 |
| 形狀裡有零星雜點 | 雜訊門檻降低、用 `at()` 量化、小形狀不要加雜訊 |
| 軟綿綿沒力 | 快進慢出（`ease.outQuart`／`outExpo`）、加 1～2 格白色閃光格、總長縮短 |
| 僵硬、像機器 | 每顆粒子的大小、速度、延遲、壽命都不同；加次要動作（火花、煙、碎片） |
| 顏色洗白 | 光暈弱一點（k 0.2～0.5）、邊緣色階加深、白色只留給最熱的核心 |
| 扁平 | 光從一邊來：左上亮、右下暗一階；底部多一階深色 |
| 太滑、像向量圖 | 顏色用硬色階；柔和只留在光暈和半透明煙 |
| 煙變成棋盤格 | 用 `SMOKE`、`VAPOUR`、`DUST` 粒子或 `p.disc`，真的半透明、上面受光 |
| 迴圈接縫跳一下 | `cycle`、`loopNoise(phase)`、整格的 `tileNoise` 捲動、`sin(phase × TAU × n)` |
| 一次性的特效「啪」一聲不見 | 結尾前讓它縮小、抖色淡出或掉落 |
| 特效很好但角色像死的 | 加動作時序：蓄力、出手換姿勢、打中停格、目標反應、收招 |
| 打擊沒重量 | 蓄力方向和出手相反、停格加長（最多 0.2 秒）、出手那格輪廓變化加大、加震動 |
| 打中的時間對不上 | 打中的時間點用特效自己的常數，不要用眼睛估的秒數 |
| 武器拿得怪 | 手肘留一點彎、長柄在胸前；揮砍時刀刃落後於手；手臂約 15 像素長不會伸長，要靠身體往前踏 |
| 手臂交叉或姿勢扁平 | 角色是四分之三側面：張開雙手時近的手在左、遠的手在右，並轉身面向鏡頭 |
