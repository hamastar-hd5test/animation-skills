# Codédex 首頁的像素風與動畫做法（2026-11-23 拆解）

對象：https://www.codedex.io/ （像素風的程式學習平台，和練功房同一類）。方法：抓靜態 HTML／CSS／首頁 JS，再用 REA 透過 CDP 對無頭 Chrome 截圖與列資源（`inspect_web_page`、`capture_web_screenshot`），圖檔只量尺寸與幀數。只看了未登入的首頁；課程內頁、地圖、戰鬥畫面沒看。
**只學做法。圖、角色、字型都是對方的，不取用。**

## 一句話

畫面是**低解析原圖放大**，動畫是**預先畫好的逐格動圖**，程式只負責疊圖層和慢慢平移。首頁沒有 canvas、沒有動畫函式庫（沒有 GSAP、Lottie、Rive、framer-motion）。

## 量到的數字

| 項目 | 數字 |
|---|---|
| 主視覺原圖解析度 | 480×320（3:2），在 1440 寬的螢幕上放大 3 倍 |
| 圖層（由遠到近） | 天空（靜態，5 色）→ 山（靜態，15 色）→ 丘陵（24 格，每格 150 ms，3.6 秒一輪）→ 吉祥物（97×120，96 格，每格 100 ms，9.6 秒一輪）→ 草地（300×320，20 格，每格 150 ms，橫向重複鋪滿） |
| 每格用色 | 5～25 色；整頁吉祥物動圖約 70 色 |
| 標題字動圖 | 146×57，13 格：幾格 100～200 ms 的掃光，然後停 3.5 秒再來 |
| 角色展示動圖 | 480×320 或更大，6～11 格，每格 180 ms（約 5.5 fps） |
| 檔案大小 | 天空 2 KB、山 3 KB、丘陵 64 KB、草地 34 KB、吉祥物 48 KB：整個主視覺約 150 KB |

## 做法

1. **一層一個背景圖。** 每層是一個絕對定位的 `div`，CSS 大致是 `background-size: auto 100%`、`background-position: center`、`background-repeat: repeat-x`、`image-rendering: pixelated`。高度撐滿，寬度不夠就橫向重複，所以任何螢幕寬度都不會破。
2. **動圖用 animated WebP，退回 GIF／PNG。** 寫兩行 `background-image`：第一行給舊瀏覽器，第二行用 `image-set()` 指定 WebP。
3. **只有天空用程式動**：`background-position` 從 0 移到 1050px，200 秒一輪，線性。很慢，幾乎察覺不到，但畫面不是死的。
4. **遠的不動、近的動。** 天空與山是靜態圖，丘陵、草地、吉祥物才有逐格動畫。動的格數少（20～24 格）、每格停得久（150 ms），這就是像素風「一格一格」的感覺。
5. **待機動畫要長。** 吉祥物 96 格、9.6 秒才重複，眨眼、蝴蝶停上來這些小事件散在裡面，看不出循環。
6. **標題用「動一下、停很久」。** 掃光只佔不到一秒，其餘 3.5 秒靜止。
7. **介面元件**：NES.css（MIT，像素邊框用多重 `box-shadow` 畫出來）加自己的 styled-components；小圖示直接 `image-rendering: pixelated` 放大；橫幅裡的小東西用 `top: 5px ↔ -5px` 上下浮動。
8. **字型分工**：像素字（PixelGrid、Dogica）只用在標題、按鈕、標籤；內文用一般無襯線字（Mulish），程式碼用 Hack。長文不用像素字。
9. **按鈕**：黃底、深色字、底部一條較深的邊，看起來像一顆有厚度的實體按鍵。

## 可以搬到練功房的

| 做法 | 練功房怎麼做 |
|---|---|
| 分層主視覺、低解析放大 | 用 `tools/px` 畫 480×320 的分層圖；`mob_anim.py` 已經能合成 animated WebP，直接沿用 |
| 遠景靜態、近景逐格 | 地圖頁或首頁的背景拆三到五層，只讓最近的一兩層動 |
| 天空極慢平移 | 一條 CSS `@keyframes`，不需要 JS |
| 待機動畫拉長到 8～10 秒 | 貓頭鷹、送件鴿現在的循環如果只有幾格，可以加入偶發小動作 |
| 標題掃光後長停 | 升級卡、關卡標題可用 |
| 像素字只給標題 | 練功房已經是系統字內文，方向一致 |

要補上的（對方首頁沒做）：減少動態效果的設定。animated WebP 沒辦法用 CSS 暫停，要另備一張靜態圖，在 `prefers-reduced-motion` 時換上。

## 不能做的

- 不取用對方的圖、角色、吉祥物、標題字圖。
- PixelGrid 等字型的授權沒有查，不拿來用；要像素中文字另找有授權的。
- NES.css 是 MIT，可以用，但它的元件是英文遊戲機風格，和練功房現有元件要先比過。
