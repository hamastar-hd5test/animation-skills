# 把 web-style-recipes 的畫風轉成風格包用的畫風句與動法

S01–S10 已經有現成的 prompt 與動法，直接用 `scene-styles.md`。這份處理另外兩個庫。表中只寫「動法」與「最該檢查」；畫風句一律現讀原檔那一條的「看得見」＋「規則」來寫，不在這裡複製，避免兩邊不同步。

## 錨點清單

```
主角：{物件}（位置、朝向、大小，例如：紅色敞篷車，畫面中下，側面朝右，佔寬 40%）
配角：{人物或次要物件}
背景：{由遠到近列出：天空／雲、天際線、路燈、招牌、路面標線、樹叢}
視角與比例：{側面平視／俯視…}，{16:9／1:1／9:16}
不可變：{使用者特別在意的，例如招牌上的字}
```

## 畫風句怎麼寫

1. 讀原檔那一條的「看得見」與「規則」。
2. 挑 3～5 個看得見的元素寫成一句英文，順序：底色或材質 → 線條 → 色彩 → 光 → 氛圍。
3. 有出處的，句尾加 `in the spirit of {作品}`，只借骨架；不寫在世創作者的「by {人名}」。
4. 寫完唸一遍：換成另一種畫風的句子，兩句要明顯不同。

## 美學 A01–A20 的動法

| A | 名稱 | 動法 | 最該檢查 |
|---|---|---|---|
| A01 | 瑞士風格 | 物件從畫面外滑入後停住，不晃 | 只有一個強調色 |
| A02 | 動態文字 | 踩節拍砸進、甩進、落下回彈 | 有一個母題，不是滿屏字 |
| A03 | 普普藝術 | 硬切、色版錯開再對齊 | 網點隨暗部變大 |
| A04 | 扁平 2D | 前中後景分層視差、漂浮顆粒 | 每個物件三階色 |
| A05 | 黏土 3D | 落地壓扁回彈、會黏一下 | 壓扁時體積不變 |
| A06 | 毛玻璃 | 只淡入與小幅上滑 | 背景夠鮮豔，玻璃看得出來 |
| A07 | Y2K 鉻 | 高光滑過、四芒星閃 | 三段反射有畫 |
| A08 | 合成波 | 路面倒影流動、霓虹微閃 | 只有粉紅與青 |
| A09 | Riso 印刷 | 套色每幾格微偏抖動 | 兩色疊出第三色；大面積（天空、桌面）用網點，實心只給主體，否則同色的主體會被底吃掉 |
| A10 | 紙張拼貼 | 12 fps 停格、剪紙啪地貼上 | 撕邊與投影 |
| A11 | 故障風 | 平常靜，關鍵拍崩一兩次 | 崩的時間很短 |
| A12 | 粒子 | 沿流場流動、聚成主角、慢轉 | 主角形體認得出 |
| A13 | 新粗獷 | 硬切、按壓陰影歸零 | 陰影實心不模糊 |
| A14 | 包浩斯 | 圓方三角逐一組裝進場 | 有一條斜軸 |
| A15 | 孟菲斯 | 輕搖、彈跳、紙屑落下 | 每塊有黑硬投影 |
| A16 | 蒸氣波 | 慢、錄影帶掃描線滾動 | 不放真人臉 |
| A17 | 像素風 | 每 2 格動一次、不補間 | 對齊像素格（與 S04 合用） |
| A18 | 等距 | 一塊塊組起來、等距平移 | 全畫面同角度 |
| A19 | 低多邊形 | 慢轉、霧中景深推移 | 三角面平塗不平滑 |
| A20 | 線條畫 | 一筆描出、有快有慢 | 線不中斷（與 S08 合用） |

## 互動配方 01–11 的視覺借用

配方是能玩的頁面，風格包只借它的「視覺特徵清單」，把互動改成一段自動播放的動作。

| 配方 | 名稱 | 動法（互動改成自動播放） | 最該檢查 |
|---|---|---|---|
| 01 | 復古自拍亭 | 閃光一下、出四格黑白底片 | 底片顆粒與黑白 |
| 02 | 熱感應 | 熱斑在主角上流動、留下冷卻殘影 | 色階是熱像色 |
| 03 | 音檔可視化 | 點陣聲紋由右往左流過畫面下緣 | 磷光殘影 |
| 04 | 白板便利貼 | 便利貼一張張貼上、馬克筆圈重點 | 便利貼不擋主角 |
| 05 | 賽博監控 | 追蹤框鎖定主角、HUD 數字跳動 | 掃描線與時間戳 |
| 06 | 萬花筒 | 鏡像切片緩轉 | 主角仍是中心 |
| 07 | 電子郵票 | 齒孔框出場景、郵戳蓋下 | 齒孔邊完整 |
| 08 | 動態文字 | 微型字聚成主角輪廓再散開 | 聚合後認得出 |
| 09 | 像素房間 | 物件逐一亮起提示可點 | 與 S04／A17 同規則 |
| 10 | 重力感應 | 小物件漂浮、輕微碰撞 | 主角不被物件蓋住 |
| 11 | Hairline | 細線等距版、靠近處做小手勢 | 線寬一致 |

讀配方檔時只讀「視覺特徵清單」那一節（`## 視覺特徵清單`）。
